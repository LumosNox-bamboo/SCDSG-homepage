- 首页首屏没有依赖 Google Fonts、第三方 CDN、外部 JavaScript、外部图片或跨域 API；关键图像均在本站仓库。
- 页面使用系统字体栈，不会从 Google 或其他字体服务下载字体。

- 其中 24 个指向 `weixin.sogou.com` 搜索结果；链接稳定性、结果精确性及欧洲网络可用性都需要人工测试。
- 投稿文字通过同源 `/api/submit-abstract` 提交到 Preview D1，不使用 Google reCAPTCHA 或其他 CAPTCHA。

- Cloudflare Pages 或购买域名本身都不能证明或保证中国大陆所有地区、所有运营商均可访问。

## 首屏与 JavaScript 降级

### 当前优点

- HTML 内含正文，不是依赖 JavaScript 渲染的单页应用。
- CSS、JavaScript 和关键图片均为同源。
- 语言切换、筛选和滑动交互失败时，原始 HTML 仍在文档中。

### 当前风险

1. `.reveal` 默认设置 `opacity: 0`，只有 JavaScript 的 Intersection Observer 运行后才显示。JavaScript 被禁用、脚本加载失败或运行异常时，部分核心内容可能不可见。
2. 投稿表由 JavaScript 拦截后使用 `fetch()` 提交；表单没有可用的服务端渐进增强 action/method 流程。JavaScript 失败时无法正常投稿。
3. 当前文件字段 disabled，但提交时的加载提示仍提到文件上传；这可能让用户误判文件状态。

后续改进建议（暂未实施）：

- 让内容默认可见，仅在确认 JavaScript 可用后添加动画初始状态。
- 增加 `<noscript>` 可见提示，但核心信息不应只放在该提示中。
- 为投稿表提供可用的标准 HTML POST fallback，或至少给出明确的备用联系方式；真实联系方式须由协会确认。
- 动画遵守 `prefers-reduced-motion`，当前移动端已有使 reveal 可见的规则，但不能替代完整的无脚本策略。

## 投稿与文件上传审计

### 文字投稿

当前行为：

- 同源 POST 到 `/api/submit-abstract`；
- 检查 Origin，拒绝跨源请求；
- 使用 honeypot 字段；
- 对请求大小、字段长度、邮箱、枚举值、摘要词数和必选同意进行服务端校验；
- API 失败时显示错误并重新启用提交按钮，用户可以手工重试；
- API 日志没有记录姓名、邮箱、机构或摘要正文。

风险与待办：

- Preview 有 D1 绑定，Production 没有；正式域绑定前必须补齐并测试生产配置。
- 没有速率限制、挑战或队列保护；恶意批量投稿防护方案为 **NEEDS HUMAN CONFIRMATION**。
- API 要求 `Content-Length` 存在；需要测试不同浏览器、代理和弱网环境是否会误触发 411。
- 没有隐私声明版本号和独立的同意证据结构。
- 失败提示支持重试，但没有草稿保存、断网恢复或请求幂等键，重复提交处理策略为 **NEEDS HUMAN CONFIRMATION**。

### 文件上传

当前状态：

- CV：只在前端声明接受 PDF，字段 disabled。
- Figure：只在前端声明接受 JPG/JPEG/PNG/WebP，字段 disabled。
- 没有 R2 绑定；
- Function 没有保存文件；
- D1 只写入空文件键并标记 `files_pending`。

因此当前无法验证：

- 实际上传成功率；
- MIME 与扩展名双重校验；
- 文件大小限制；
- 重试/分片；
- 私有下载权限；
- R2 CORS；
- 同名覆盖；
- 删除和导出。

这些项目必须在数据存储架构落实后，用非真实个人资料进行专项测试。

## 不应采用的关键依赖

- 不使用 Google reCAPTCHA 保护投稿或上传。
- 不从 Google、GitHub Raw 或公共 CDN 加载首屏关键 CSS、JS、字体或图片。
- 不让公众号、搜狗、社交网络或嵌入视频成为协会内容的唯一副本。
- 不把 R2 bucket、`r2.dev` 或私人文件子域公开。
- 不因域名在 Cloudflare 注册就声称“中国所有地区均可访问”。

## 中国大陆三网与欧洲人工测试清单

每次生产发布及域名迁移后，至少执行一次。测试人员、地点、运营商、设备、时间和结果应写入内部测试记录。

### 中国移动

- 不使用 VPN，从移动 4G/5G 打开裸域首页、协会介绍、活动和论坛页。
- 冷缓存记录 DNS、TLS、首屏文字、首屏主图和完整加载结果。
- 切换弱网后检查基础页面是否仍可阅读。
- 测试中文/德文切换和活动滑动。
- 使用虚假测试内容提交投稿，确认成功、失败和再次重试提示。
- R2 上线后测试允许类型、拒绝类型、超限、断网和重试。

### 中国联通

- 重复移动网络全部项目。
- 单独测试 `www`、Pages 地址和保护域的 301 是否保留路径/query。
- 抽查至少 5 个搜狗/微信活动链接，记录结果是否为目标文章。

### 中国电信

- 重复移动网络全部项目。
- 检查本地 SVG 地图、二维码及 WebP/JPG/PNG 图片。
- 测试 DNS 首次解析和 SSL 证书链。

### 欧洲网络

- 至少使用德国固定宽带和德国移动网络。
- 如有条件，增加一个非德国欧盟网络。
- 检查中德双语、所有官方嘉宾/协办资料外链和搜狗/微信链接。
- 测试 GDPR 隐私声明、同意记录、数据导出和删除请求入口（上线后）。
- 使用键盘、屏幕阅读器或浏览器无障碍检查完成表单。

### 通用故障场景

- 禁用 JavaScript；
- 禁用第三方请求；
- 清空 DNS/浏览器缓存；
- 模拟 Slow 3G、离线、上传中断；
- API 返回 400、411、413、429、500 和超时；
- 重复点击提交；
- 刷新后重试；
- 文件名含中文、空格、同名及特殊字符；
- 不支持 WebP 的旧环境；
- 浏览器返回/前进；
- 屏幕宽度 320px、平板及桌面。
